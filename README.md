# Fintech Data Pipeline & Capstone Onboarding

## Project Overview
This repository contains the baseline environment setup, data sourcing strategy, and initial raw financial data acquisition pipeline for the fintech data analytics capstone project.

## Directory Structure
- `data/raw/`: Storage for unedited data fetched directly from APIs (Alpha Vantage, Yahoo Finance).
- `data/processed/`: Cleaned and transformed datasets ready for modeling.
- `scripts/`: Python automation scripts for data extraction and integrity validation.
- `notebooks/`: Exploratory Data Analysis (EDA) and environment testing Jupyter notebooks.
- `outputs/`: Generated charts, logs, and summary reports.
- `docs/`: Sourcing Strategy Document (SSD.pdf) and documentation.
